# Nexum Cloud VPS Client

**[Русский](README.md) · [English](README.en.md)**

> Windows-клиент Nexum Cloud для подключения собственных компьютеров и инструментов к AI-ассистентам через **Model Context Protocol (MCP)**. Клиент открывает исходящее защищённое соединение с Nexum Cloud VPS, а доступ выдаётся через браузерную авторизацию. Не требуется открывать входящие порты домашней сети.

## Что такое Nexum

Nexum — инфраструктура удалённого взаимодействия AI-ассистентов с устройствами пользователя. В отличие от подключения отдельного локального инструмента к каждому AI-приложению, Nexum предлагает общий серверный вход **MCP + OAuth** и клиентское приложение, которое связывает ваши устройства с облачным шлюзом.

- **Свои устройства.** Клиент запускается на компьютере владельца; выполнение операций происходит на выбранном устройстве, а не на веб-сайте.
- **Исходящее соединение.** Клиент соединяется с облачным сервером, не публикуя локальный SSH/RDP/FTP-порт.
- **Отдельная авторизация.** Вход через браузер с OAuth 2.0 / PKCE; токены Windows-клиента сохраняются в Windows Credential Manager.
- **Доступ через MCP.** Совместимые AI-клиенты подключаются к защищённому публичному MCP endpoint и вызывают типизированные инструменты.
- **Управляемость.** Сервер связывает устройство с аккаунтом, проверяет принадлежность и разрешения, ведёт учёт вызовов и поддерживает отзыв доступа.
- **Независимые агенты.** Подключения и идентификаторы устройств не должны смешиваться между пользователями; Windows VPS-клиент работает независимо от прежнего Nexum и отдельного VM-клиента.

**Актуальный доступный сервер:** [https://stage.nexum-mcp.ru](https://stage.nexum-mcp.ru/) (действующий публичный экземпляр с названием stage). Публичный MCP URL: `https://stage.nexum-mcp.ru/mcp`. Основной домен `nexum-mcp.ru` пока используется как сайт/документация; **не заменяйте stage на основной домен в параметре `--server`** без отдельного объявления о переносе.

## Быстрый запуск в Windows

1. [Откройте последний релиз](https://github.com/TheLane/nexum-cloud-vps-client/releases/latest) и скачайте `NexumCloudVPS-Client-windows-x64.zip`.
2. Проверьте SHA-256 из файла `SHA256SUMS.txt`, который приложен к релизу. Перед запуском убедитесь, что архив получен с официального репозитория.
3. Распакуйте архив в постоянную папку, например `C:\NexumCloudVPS`. **Не запускайте EXE прямо из ZIP**.
4. Дважды щёлкните `Connect-Nexum-Cloud-VPS.cmd`. Он запустит клиент с правильным адресом сервера.
5. В открывшемся браузере зарегистрируйтесь или войдите в Nexum, подтвердите доступ. Оставьте окно клиента работающим — оно поддерживает соединение с VPS.
6. Подключите поддерживаемый AI-клиент к `https://stage.nexum-mcp.ru/mcp`, пройдите его отдельную OAuth-авторизацию и выбирайте доступные инструменты.

Никакой пароль не нужно вводить в командной строке или передавать разработчикам. Если браузер не открылся, смотрите [руководство по устранению проблем](docs/TROUBLESHOOTING.md).

### Запуск вручную

```powershell
.\nexum-cloud-client.exe --server https://stage.nexum-mcp.ru status
.\nexum-cloud-client.exe --server https://stage.nexum-mcp.ru connect
```

Дополнительный агент (каждый `--agent` создаёт отдельный Agent):

```powershell
.\nexum-cloud-client.exe --server https://stage.nexum-mcp.ru connect --agent "My workstation"
```

Список аргументов: `nexum-cloud-client.exe --help` и `nexum-cloud-client.exe connect --help`. Выход из приложения прерывает поддерживаемое им соединение. Завершение работы и отзыв разрешений — разные действия; для отзыва используйте управление устройствами/подключениями в аккаунте или предусмотренный флаг `--logout`.

## Как устроено подключение

```text
AI assistant (MCP client)
        │ HTTPS / MCP + OAuth
        ▼
stage.nexum-mcp.ru ── Authz / Gateway / Core / account control
        │ WSS, проверенная идентичность устройства
        ▼
Nexum Cloud VPS Windows Client (исходящее соединение)
        │
        └── Типизированные инструменты / локальная среда пользователя
```

Сервер не является «удалённым рабочим столом» с безусловным доступом. Конкретные действия зависят от версии клиента, выданных разрешений, конфигурации устройства и возможностей AI-приложения. MCP-вызовы могут изменять данные: проверяйте запросы AI перед предоставлением опасных полномочий.

## Системные требования

- **Windows x64** (публичный установочный пакет рассчитан на Windows; сборки macOS/Linux пока не заявлены).
- Доступ по HTTPS/WSS к `stage.nexum-mcp.ru`, рабочий браузер, пользовательский аккаунт Nexum.
- Для сборки: Rust stable, Cargo, Windows SDK/C++ toolchain, соответствующие зависимости Rust.
- Для работы с MCP нужен AI-клиент, поддерживающий удалённый MCP и предусмотренную сервером OAuth-авторизацию.

## Состав выпуска

В публичном репозитории размещены только **готовый Windows EXE**, командный файл запуска и подробная документация на русском и английском. **Исходный код Nexum Cloud VPS Client здесь не публикуется.**

Устанавливайте приложение через [последний GitHub Release](https://github.com/TheLane/nexum-cloud-vps-client/releases/latest): архив Windows x64, отдельный EXE, контрольные суммы SHA-256. Такая же проверенная программа размещена в папке [client/](client/).

Это развивающееся программное обеспечение; часть функций может отличаться в зависимости от версии VPS и устройств. **Не публикуйте сюда логи с токенами, ключами и личными файлами.** При обновлениях сохраняйте доступ к рабочему клиенту, проверяйте новый выпуск отдельно и не удаляйте рабочую конфигурацию.
